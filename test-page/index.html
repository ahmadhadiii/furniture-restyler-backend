Reference only - these help the model understand the room's real materials/lighting/architecture, but only the main photo above gets restyled and returned.

Room type + color are sent as-is; the backend builds the actual hidden prompt from them (same as the real app). Leave "Prompt override" below blank to use that - only fill it in to bypass categories entirely for debugging.

Only steers furniture-size wording in the hidden prompt (e.g. compact vs large sofa/bed, 6-seat vs 8-seat dining table) - not precise geometric placement. The native Android app also offers an AR-assisted scan for this, but that can't be replicated here: Safari on iOS has no WebXR support at all (confirmed against caniuse.com), so browser-based AR isn't technically possible on iPhone regardless of how this page is built.

The backend automatically detects walls/ceiling/windows/doors and keeps them pixel-identical to the original photo - only furniture gets regenerated. No manual masking needed.
